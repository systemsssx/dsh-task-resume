01 / WHY

重要的东西，
不该只活 3 秒。

长任务里真正会被漏掉的，往往不是报错本身，而是「跑完了」「要你选」「降级了」这三类安静的事件。

你真正需要看见的
普通通知 / toast
提示交接
×长任务收尾：跑完了，但结论在里面
滚动几十屏去找，或者重新问一遍
✓一条标题钉在面板最上面，点开侧栏就在
×需要你决策：AI 停在那等二选一
被下一条消息顶走，回头已经找不到
✓warn 常驻 + 未读圆点，不会随滚动消失
×出错了但没停下来：降级 / 跳过 / 部分失败
一闪而过，十分钟后才想起来
✓error 红点一直亮着，直到你打开面板
×会话要交接：上下文快满了
手动复制粘贴，或从零再解释一遍
✓一键写 HANDOFF、开新会话，上下文完整带过去
普通通知是「喊一声」，提示交接是「贴在冰箱上」。 ——所以它值得一个常驻的侧边栏入口，而不是一枚 3 秒就消失的 toast。
02 / FEATURES

一块安静的公告板。

零第三方依赖、纯本地存储。级别只体现在左侧圆点，正文永远同一套排版。

ENTRY
◎

侧栏原生入口

紧跟「项目工坊」的一行提示交接，DOM 克隆原生行样式；位置被占就依次下移，永不覆盖别家插件。

TOOL
↗

post_hint 工具

Agent 自己推提示：任务完成、需要决策、降级失败。标题 + 可选正文 + info / warn / error 三级。

STATE
◐

已读 / 未读

未读实心圆点、已读空心；最多保留 50 条环形缓冲，最新在上。可选 JSON 持久化，重启不丢。

HANDOFF
⇥

交接会话

写 HANDOFF-*.md + 归档 session.jsonl + 开新会话；Computer Use / 标准双模式，均完全权限。

AUTO
⏱

真实阈值自动交接

只统计已完成的自动压缩轮数，状态行显示真实 x/y；手动 /compact 不计入，不写死数字。

LOCAL

零第三方依赖、无网络请求；数据在内存或你指定的 JSON 里，随手可删。

04 / API

让 Agent 自己贴便签。

模型通过 post_hint 推提示；本地脚本也能走 /hint/push。

参数类型说明
title必填一行标题，列表里加粗显示（截断到 160 字）
body可选补充说明：发生了什么、下一步做什么（截断到 1200 字）
level可选info · warn · error，默认 info
返回值：{ ok, id, level, unread, total }
title 可省略但 body 必须存在：此时正文第一行会被提升为标题。
JSONpost_hint · 工具调用
// Agent 调用 post_hint，把一条提示推进面板
{
  "title": "构建完成：12 个文件已打包",
  "body":  "dist/ 体积 312 KB，滚动、焦点与响应式断点全部通过。",
  "level": "info"
}

// 本地脚本也可以直接走 HTTP
curl -s -X POST http://127.0.0.1:9760/hint/push \
  -H 'Content-Type: application/json' \
  -d '{"title":"部署完成","level":"info"}'

06 / INSTALL

三分钟装好。

放进 ~/.dsh/plugins/，加进 profile，重启 DSH。插件自带 bundle patch，不用手改内部文件。

  1. 1
    放进插件目录
    目录名必须是 dsh-hint-handoff，与 package.json 的 name 一致。
  2. 2
    装配到 profile
    编辑 ~/.dsh/profiles/desktop/package.json：加进 bundles 与 dependencies（见右）。
  3. 3
    重启 DSH
    侧边栏「更多」下方出现 ◎ 提示交接；点击即开面板。
  4. 4
    推一条试试
    让 Agent 调用 post_hint，或 curl /hint/push。

07 / FAQ

常见问题。

还有没覆盖的？去 Discussions 的 Q&A 分类直接问。

装好后侧边栏没有「◎ 提示交接」？

确认 profile 的 bundles 里有 dsh-hint-handoff、dependencies 里有对应 link:，目录名与 package.json 的 name 一致，然后完全重启 DSH（不是只刷新页面）。

提示默认只存在内存里，重启会丢吗？

会。需要保留就设置 persistPath（如 .dsh-hints.json），插件会在每次变更后 250ms 防抖落盘。

自动交接什么时候触发？

只统计已完成的自动压缩轮数（手动 /compact 不计）。达到 threshold 才触发；状态行显示真实计数 x/y。

「交接会话」点了没反应？

交接只在安全时机执行：当前回合结束、没有未返回的工具调用、没有压缩在进行。错误会显示在状态行，不会静默失败。

Computer Use 模式不见了？

这是预期降级：当前 profile 没有提供 computer-use preset 的 bundle（例如 dsh-orb）。补装后重启即可出现。

会上传我的提示吗？

不会。插件零第三方依赖、没有网络请求，数据只在本机内存或你指定的 JSON 文件里。
